# 제일풍경채 입주준비 계산기

신축 아파트 입주 시점에 필요한 현금을 분양 잔금, 대출, 취득 관련 세금, 등기비용, 이사·시공·가전·가구 비용까지 한 화면에서 계산하는 반응형 웹 애플리케이션입니다. 모든 계산은 브라우저에서 수행하며 입력값은 사용자의 브라우저 `localStorage`에만 저장됩니다.

## 주택형·층별 분양가격 선택

`예시 단지에서 선택`과 `직접 입력`을 지원합니다. 예시 단지는 2023년 9월 15일 공고된 **광주연구개발특구 첨단3지구 첨단 제일풍경채 A2BL**이며, 59A·59B·84A·84B의 기준층·5층·4층·3층·2층·1층 공급금액과 납부일정을 제공합니다.

- 선택 시 분양가격, 계약금 1·2차, 중도금 6회, 잔금이 자동 입력됩니다.
- 발코니 확장비는 공급금액과 분리되며 주택형 선택 시 59A 8,290,000원, 59B 8,790,000원, 84A 10,290,000원, 84B 8,440,000원이 자동 적용됩니다.
- 각 중도금 회차는 미납, 본인 자금 납부, 중도금 대출 납부 중 하나를 선택할 수 있습니다.
- 중도금 대출 납부액은 시행사에 납부된 금액이므로 남은 분양대금에서 제외하고, 입주 시 상환·전환할 원금으로 한 번만 반영합니다.
- 예시값을 불러온 뒤에도 모든 금액과 납부 상태를 수정할 수 있습니다.

## 계산식

- 총 계약금액 = 항목별 입력(분양가 + 확장비 + 옵션비 + 기타 계약금액) 또는 직접 입력한 총액
- 현재까지 납부한 금액 = 계약금 + 현재까지 납부한 옵션비 + 직접 납부한 중도금
- 시행사 납부액 = 계약금 + 현재까지 납부한 옵션비 + 본인 자금 납부 중도금 + 중도금 대출 납부액
- 남은 분양대금 = `max(총 계약금액 - 시행사 납부액, 0)`
- 직접 입력 납부일정의 자동 계산 잔금 = `max(분양가 - 계약금 1·2차 - 중도금 합계, 0)`
- 중도금 대출 상환 예정 원금 = 중도금 대출 납부액
- 감면 전 취득세 = 총 계약금액 × 사용자가 입력한 취득세율
- 감면 후 취득세 = `max(감면 전 취득세 - 감면금액, 0)`
- 세율 입력 농어촌특별세 = 사용자가 선택한 과세표준(총 계약금액 또는 적용된 취득세 감면액) × 입력 세율
- 직접 입력 농어촌특별세 = 사용자가 입력한 금액
- 취득 관련 세금 합계 = 감면 후 취득세 + 지방교육세 + 농어촌특별세 + 기타 세금
- 부대비용 합계 = 등기 및 대출비용 + 체크된 입주 준비비용
- 총 필요금액 = 남은 분양대금 + 중도금 대출 상환 예정 원금 + 중도금 대출 후불이자 + 취득 관련 세금 + 부대비용
- 대출 충당금액 = 잔금대출 예정금액
- 비율 입력 잔금대출 예정금액 = `(분양가 + 발코니 확장비) × 입력 비율`
- 현재 입력 기준 준비 현금 = `max(총 필요금액 - 대출 충당금액, 0)`
- 자금 여유분 = `max(대출 충당금액 - 총 필요금액, 0)`
- 권장 준비금액 = 현재 입력 기준 준비 현금 + (현재 입력 기준 준비 현금 × 예비비율)

중도금 대출 원금은 남은 분양대금과 상환 예정 원금에 각각 한 번씩만 반영해 중복 계산을 방지합니다. 원 단위 금액과 세율은 내부에서 정수로 계산합니다.
납부액 초과 여부는 본인 납부액뿐 아니라 중도금 대출 납부액까지 포함한 시행사 납부액을 기준으로 검사합니다.

## 주요 입력 항목

- 분양가, 발코니 확장비, 옵션비, 기타 계약금액 또는 총 계약금액 직접 입력
- 계약금, 직접 납부한 중도금, 중도금 대출 원금·후불이자, 잔금대출
- 취득세율·감면액, 지방교육세율 또는 직접 입력액, 농어촌특별세율 또는 직접 입력액, 기타 세금
- 국민주택채권, 법무사, 등기·인지세, 근저당권, 보증료와 대출 수수료
- 관리비, 이사·청소·시공, 커튼, 에어컨, 가전, 가구, 인터넷 등 선택 비용
- 0%, 3%, 5%, 10% 또는 직접 입력 예비비

## 취득세 기준을 직접 입력하는 이유

취득세율과 감면 적용 여부는 취득 시점의 법령, 주택 수, 가격, 면적, 지역과 생애최초 등 개인 조건에 따라 달라질 수 있습니다. 농어촌특별세 역시 일반 취득 관련분과 감면 관련분의 과세표준이 다를 수 있고, 국민주택규모 이하 서민주택 등에는 비과세가 적용될 수 있습니다. 변경 가능한 법률 기준을 코드에 하나의 값으로 고정하지 않고, 관할 지방자치단체 등에 확인한 계산 기준·세율·감면액 또는 세액을 사용자가 직접 입력하도록 설계했습니다.
