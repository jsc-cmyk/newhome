# 제일풍경채 입주준비 계산기

신축 아파트 입주 시점에 필요한 현금을 분양 잔금, 대출, 취득 관련 세금, 등기비용, 이사·시공·가전·가구 비용까지 한 화면에서 계산하는 반응형 웹 애플리케이션입니다. 모든 계산은 브라우저에서 수행하며 입력값은 사용자의 브라우저 `localStorage`에만 저장됩니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 개발 서버가 안내하는 주소로 접속합니다.

## 빌드·검사·테스트

```bash
npm run build
npm run typecheck
npm run lint
npm test
```

## 계산식

- 총 계약금액 = 항목별 입력(분양가 + 확장비 + 옵션비 + 기타 계약금액) 또는 직접 입력한 총액
- 현재까지 납부한 금액 = 계약금 + 직접 납부한 중도금
- 남은 분양대금 = `max(총 계약금액 - 현재까지 납부한 금액, 0)`
- 감면 전 취득세 = 총 계약금액 × 사용자가 입력한 취득세율
- 감면 후 취득세 = `max(감면 전 취득세 - 감면금액, 0)`
- 취득 관련 세금 합계 = 감면 후 취득세 + 지방교육세 + 농어촌특별세 + 기타 세금
- 부대비용 합계 = 등기 및 대출비용 + 체크된 입주 준비비용
- 총 필요금액 = 남은 분양대금 + 중도금 대출 후불이자 + 취득 관련 세금 + 부대비용
- 대출 충당금액 = 잔금대출 예정금액
- 실제 준비 현금 = `max(총 필요금액 - 대출 충당금액, 0)`
- 자금 여유분 = `max(대출 충당금액 - 총 필요금액, 0)`
- 권장 준비금액 = 실제 준비 현금 + (실제 준비 현금 × 예비비율)

중도금 대출 원금은 이미 분양대금 납부에 사용된 자금으로 간주해 총 필요금액에 다시 더하지 않습니다. 원 단위 금액과 세율은 내부에서 정수로 계산합니다.

## 주요 입력 항목

- 분양가, 발코니 확장비, 옵션비, 기타 계약금액 또는 총 계약금액 직접 입력
- 계약금, 직접 납부한 중도금, 중도금 대출 원금·후불이자, 잔금대출
- 취득세율·감면액, 지방교육세율 또는 직접 입력액, 농어촌특별세, 기타 세금
- 국민주택채권, 법무사, 등기·인지세, 근저당권, 보증료와 대출 수수료
- 관리비, 이사·청소·시공, 커튼, 에어컨, 가전, 가구, 인터넷 등 선택 비용
- 0%, 3%, 5%, 10% 또는 직접 입력 예비비

## 취득세 기준을 직접 입력하는 이유

취득세율과 감면 적용 여부는 취득 시점의 법령, 주택 수, 가격, 면적, 지역과 생애최초 등 개인 조건에 따라 달라질 수 있습니다. 변경 가능한 법률 기준을 코드에 하나의 값으로 고정하지 않고, 관할 지방자치단체 등에 확인한 세율과 감면액을 사용자가 직접 입력하도록 설계했습니다.

## 주의사항

본 서비스의 결과는 자금계획을 위한 참고치이며 법률·세무·금융 자문이 아닙니다. 실제 납부 전 관할 지방자치단체, 금융기관 또는 법무사에게 취득세, 감면, 채권 할인비용, 등기비용과 대출비용을 확인하세요.
